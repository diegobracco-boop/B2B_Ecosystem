====================================================================
  INPUTS PLANNING P&L — pipeline de datos (planas + JSON canónicos)
  Reemplaza a Toqan: genera las planas localmente y publica los JSON
  por concepto en Drive. Fuente única para TODAS las landings.
====================================================================

QUÉ HACE
--------
CSV crudos (Planning-PBI)  ->  PLANAS (Marca|LoB|Canal|Pais|Producto|P&L N1..N6|
Managerial|Fecha|Monto)  ->  JSON canónico por concepto  ->  Drive.

Conceptos: budget, forecast, runrate (RR), lastrunrate (LRR), actuals.
Los JSON van a la carpeta Drive: 1XqQPL_rlS0NRIPUnPfj5nALBTn7kAOQV
(budget.json, forecast.json, runrate.json, lastrunrate.json, actuals.json)

REGLAS DE NEGOCIO
-----------------
- SIN PPA por default (suma Reverso AxI). Con PPA: pasar --con-ppa.
- Canal: solo B2B abre MAY/MIN; B2B2C y B2C se colapsan a 'total'.
- JSON agregado sobre Marca (no se incluye).
- Año fiscal = Abr(N-1) a Mar(N). Proyecciones = FY27 (abr26-mar27).
- Actuals por FY combina 2 años calendario (Abr-Dic del fy-1 + Ene-Mar del fy).
  FY2027 se actualiza cada mes; FY previos se corren 1 sola vez.

REQUISITOS (una vez por persona)
--------------------------------
- pip install pandas openpyxl google-auth google-auth-oauthlib google-api-python-client
- OneDrive sincronizado (Planning-PBI + Control de Gestión). Rutas se resuelven solas.
- python auth_drive.py  (autoriza Drive, crea token_drive.json). credentials_drive.json ya está.

USO
---
Mensual (todo + subir a Drive):   run_all.bat
Individual:
   python plana_projections_builder.py budget|forecast|runrate|lastrunrate
   python plana_actuals_builder.py 2027          (o 2024/2025/2026 -> una vez)
   python json_builder.py budget|forecast|runrate|lastrunrate|actuals|all  [--no-upload]

ARCHIVOS
--------
pnl_common.py                 rutas portables + auth Drive (scope completo)
plana_projections_builder.py  planas budget/forecast/RR/LRR
plana_actuals_builder.py      plana actuals por año fiscal
json_builder.py               planas -> JSON canónico -> Drive
run_all.bat / auth_drive.py   runner / autorización
